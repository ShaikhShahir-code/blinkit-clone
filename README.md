# Blinkit Clone 🛒⚡

A front-end clone of the Blinkit website built using HTML & CSS.  
The project replicates the core layout of the Blinkit homepage and focuses on creating a clean and user-friendly UI.  
Currently optimized for desktop screens (non-responsive).

---

## 🚀 Features
- Responsive layout  
- Navigation bar with categories 🧭  
- Hero banner & promotional section 🛍️  
- Product listing grid 🍎🥦🥫  
- Footer with links & info 🔻  

## 🛠️ Tech Stack
- **HTML**  
- **CSS**
